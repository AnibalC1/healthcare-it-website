ADMISSION PROCESS

Admission Process

STEPS:

  • Enter Patient into Registration System
  • Interview Patient
  • Update History Tab
  • Obtain Admission Orders
  • Complete Admission Tab
  • Complete Medication Orders Tab if applicable
  • Complete Ancillary Orders Tab if applicable

Facility New Inpatient Admission

Once patient is listed as an inpatient in Registration software the HCS process starts.

HISTORY TAB

Medication Query is initiated with an inpatient admission. Query will pull prescriptions filled by patient within the last 120 days.

*Medications not queried are: VA, DOD, Methadone clinics, OTC and inpatient hospitals.

Workflow on updating History Tab

Clinicians are expected to update or inactivate EVERY line item based on interview with patient. Medications must include dose, route and frequencies *unknown is allowed if appropriate.

EVERY medication must have CV (clinician verified) or IM (inactive medication) in the source column for the History tab to be complete.

Updating Preferred Pharmacy

Staff should select preferred pharmacy to prepare for discharge. In the “Preferred Pharmacy” box, begin entering Name, City, State or ZIP to start search. Can search “Walgreens in Springfield” or “CVS in 36117”. Make selection from results.

*Any pharmacy that produced results from the query will show as an option.

ADMISSION TAB

Admission tab shows only active medications from the history tab. Medications marked as IM (Inactive Medication) will not flow to Admission tab.

Notify the provider of active home medications and mark Continue or Stop based on orders from provider.

*OPTION - Select “Add Favorites” and enter admission orders (medication and ancillary orders)

Once all medications have been addressed, select the red “Send to Pharmacy” button. Button will turn green when synced.

MEDICATION ORDERS TAB

Medication Orders tab will show all medications that were synced to pharmacy.

Additional medication orders can be entered individually using the “ADD” button or as a group using the “ADD FAVORITES” button

A medication order must have Medication name, dose, route, frequency and indication for it to be saved as an active order.

ANCILLARY ORDERS TAB

Ancillary orders tab will show Orders from the admission.

Additional ancillary orders can be entered individually using the “ADD” button or as a group using the “ADD FAVORITES” button.

Some ancillary orders require a frequency or additional information to be saved as an active order.
